Python SRE Scripts

A practical collection of Python scripts and automation tools built to develop Python, Linux, automation, troubleshooting, and Site Reliability Engineering (SRE) skills.

This repository focuses on solving realistic operational problems that an SRE, Linux Engineer, DevOps Engineer, or Production Support Engineer may encounter in day-to-day infrastructure and application operations.

The goal is not to build random Python exercises, but to progressively turn Python knowledge into reliable, modular, testable, and production-oriented automation.

Problem Statement

SRE and production support work frequently involves repetitive operational tasks such as checking system health, analyzing logs, validating configurations, monitoring services, checking connectivity, collecting metrics, and responding to incidents.

These tasks can often be automated with Python.

However, writing a script that simply works is different from building automation that is:

Modular
Maintainable
Reliable
Testable
Observable
Easy to extend
Safe to run in production environments

This repository is designed to bridge that gap by building a series of progressively more advanced Python projects based on real-world SRE and production-support scenarios.

Solution

python_sre_scripts contains a progressive set of Python labs and automation projects.

The early projects focus on Python fundamentals and Linux automation. Later projects introduce APIs, concurrency, asynchronous programming, testing, monitoring, alerting, FastAPI, and more advanced software design concepts.

Each project is designed to solve a specific operational problem while introducing new Python and SRE concepts.
